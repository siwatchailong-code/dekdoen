เด็กเดิน V8 Professional

ปรับจาก V7 ตามบรีฟ:
- ใช้โลโก้เด็กเดินที่ผู้ใช้ส่งล่าสุด
- เอาอิโมจิตกแต่งออกจาก UI
- ดีไซน์เน้นความเป็นมืออาชีพ สะอาด อ่านง่าย
- มี 3 บทบาท: แอดมิน / ลูกค้า / ไรเดอร์
- แอดมิน: สร้างงาน หลายจุด สินค้า/รูปต่อจุด ราคา และลิงก์
- ลูกค้า: รายละเอียดงาน จุดรับหลายจุด จุดส่ง และแนบรูป
- ไรเดอร์: ใบงาน ลำดับเส้นทาง รายการสินค้า และปิดงาน
- เป็น frontend prototype; Google Maps และ backend จริงยังต้องเชื่อมต่อในขั้น production
